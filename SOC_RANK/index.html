数据说明
· 数据来源：B站 @做一只有梦想的匡匡喵 ↗（UID 398038578）。
· 数码主题只保留芯片名与跑分；切到波普主题会多出搭载机型和视频标题，那些标题能点，直接跳 B站对应那期。
· 芯片成绩 = 搭载该芯片的机型在 UP 主稿件里的实测值，同芯片多机型时取最高分作代表。
· 带「预估」角标和斜纹条的是外部参考值，UP 主稿件里没跑过这几台，不属于实测：
　骁龙 820（8848 M4 / 格力 色界 / 三星 W2017）≈ 单核 340 · 多核 780；
　骁龙 450（OPPO A5）≈ 单核 168 · 多核 762。
　取值来自 CPU-Monkey / NanoReview / CPUDB 等多站 GB6 样本均值，只用来定它在榜上的大致位置，别当实测引用。
· 不同系统版本、散热条件、后台负载都会影响成绩，跨年机型只能看大致档位。
· 安兔兔成绩为稿件中标注值，仅作参考——两套基准算法不一样，别直接横向比。
· 稿件里「骁龙 8 至尊版 单核 2817 / 多核 9271」是对比引用值，已按 UP 主自机成绩 2871 / 9217 收录。
